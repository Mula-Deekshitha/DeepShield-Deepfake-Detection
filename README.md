# 🛡️ DEEPSHIELD: Multi-Modal Deepfake Detection Engine

> **A real-time, CPU-optimized forensic framework combining Spatial Texture, Frequency Spectrum, and Facial Landmark Graph modalities for scalable deepfake detection.**

---

## 📸 System Overview

DEEPSHIELD is designed to detect high-quality facial manipulations across unseen generative algorithms (GANs, Diffusion Models, FaceSwap). By combining three distinct forensic channels, the system evaluates structural, spectral, and textural features simultaneously to maintain high generalization accuracy.

## ✨ Key Features

* **Tri-Branch Hybrid Architecture:**
  * **Spatial Stream:** Captures boundary blending artifacts, color inconsistencies, and local texture noise.
  * **Frequency Stream:** Applies 2D Fast Fourier Transforms (FFT) to expose high-frequency upsampling grid noise generated by modern synthetic models.
  * **Structural Graph Stream:** Extracts 468 3D facial landmark nodes (via MediaPipe) to evaluate physical geometry shifts and asymmetrical facial movement.
* **Low-Latency Inference:** Exported to static ONNX graphs with dynamic input binding and INT8 quantization for fast execution on standard desktop CPUs (~15–30 ms per frame).
* **Explainable AI (Grad-CAM++):** Displays spatial activation heatmaps over video frames, highlighting specific facial regions flagged for manipulation.
* **Interactive Dashboard:** Built with Streamlit for real-time video upload, frame processing, and visual evaluation metrics.
